# Uber-Fare-Prediction-Analysis
Uber Fare Prediction Analysis using Python and Machine Learning to predict ride fares based on trip-related data.
# Uber Fare Prediction Analysis

## Project Overview
This project predicts Uber ride fares using machine learning techniques.

## Dataset
The dataset contains information such as pickup location, drop-off location,
distance, passenger count, and fare amount.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning
Random Forest Regression is used to predict Uber fare prices.

## Project Files
- Uber_Fare_Prediction_Presentation.pptx – Project presentation
- Uber_Fare_Prediction.ipynb – Python code and analysis
- dataset/ – Dataset used for the project
- outputs/ – Graphs and results
